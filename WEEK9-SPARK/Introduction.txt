Apache Spark
================

Apache spark is a 

general purpose
In memory
compute engine

================
compute engine
================

hadoop provide 3 things

1.HDFS - storage
2.mapreduce - computation
3.YARN - resource manager

spark is a replacement or alternative of Mapreduce

spark says I am a plug and play so I need 2 things which are

spark says tell me where the data is 

Storage - from I can take the data (local storage, HDFS, AWS S3 etc)
Resource manager - to control the resources on the cluster (YARN, apache Mesos, Kubernetes)


============
In memory
============

HDFS mr1	HDFS	mr2	 HDFS	mr3	 HDFS	mr4  HDFS	mr5 HDFS

takes input from hdfs and write the tranformation results back to disk(hdfs)

if we have 100 mapreduce jobs then we require 100*2 200 disk(i/o) (read-write operations) accesses

lot of i/o means - serialization and deserialization happens at the back end.

serialization nature means compact in the nature - saves storage
deserialization nature means non-compact - more storage required

when we store in serialization mode and when we want to feed the data to spark that has to be deserialized so we incur CPU costs

it is a trade-off between storage versus incuring cpu costs when processing

recommendation is to keep deserialized and save cpu costs.

but what happens incase of 100 jobs we end up reading one time from hdfs and finally it will write to hdfs.

all remaining things happens in memory.

so 100 tranformations but only 2 disk IO'save

that is why spark is said to be 10 to 100 times faster than mapreduce.

HBase - is a distributed database management system which runs on top of hadoop.

Hbase:

1.Distributed - stores data in HDFS
2.Scalable - Capacity directly proportional to number of nodes in the cluster.
3.Fault tolerant - Piggybacks on hadoop (Replication factor)
4.Columnar storage
5.denormalization is preferred ( store the data in a big table)- Normalization ( big table is divided into smaller tables ) is preferred in traditional systems.
6.we do join, group by and orderby in traditional systems however you can only perform CRUD operations like create, read, update and delete.
7.ACID - row level
whenever we are trying to update multiple columns for a single row.

then either all of them will be updated or none will be updated. this means for a single row level Hbase is automic.

when we talk about updates for multiple rows in hbase then there is no guarantee. - 

even if the update is on the same column in multiple rows - we can't guarantee that it will update all the rows.

1) How to create partitions based on year and month?
======================================================

2022/01
2022/02
2022/03

on-prem traditional databases.

date format: dd-mm-yyyy

default spark date format: yyyy-MM-dd

df = spark.read \
	.format("csv") \
	.option("treatEmptyValuesAsNulls","true") \
	.option("nullValue",null) \
	.option("path","/file.csv") \
	.load()
	
here Hiredate column came as string so we convert that to date below by mentioning the format that is coming from source.
and if any nulls in Hiredate column we are giving dummy date
	
df1= df.withColumn("Hiredate",to_date("Hiredate",'dd-mm-yyyy').fillna("Hiredate":'9999-12-31')

df2 = df1.withColumn("YEAR",date_format("Hiredate",'yyyy')) \
		.withColumn("MONTH",date_format("Hiredate",'MM'))

df1.write \
	.format("csv") \
	.partitionBy("YEAR","MONTH") \
	.mode("overwrite") \
	.option("path","/data/")

4) How to remove duplicate rows in dataframe
===============================================

1) distinct()
2) dropDuplicates() / drop_duplcates()
3) window function with row_number
4) groupby with count()

df = spark.read \
		.format("csv") \
		.option("path","file.csv")
		.load()

distinct() & dropDuplicates(without mentioning any columns) both works the same way that all the column in a row should be equal then only these two 
will consider that as duplicate row.
		
df.dropDuplicates(["id"]) //remove dupes based on id column

how to keep the latest one when deleting as above one removes the latest record and keep the old one when there are multiple records

df.orderBy(col("updated_date").desc()).dropDuplicates(["id"])

# window function with row_number

df1= df.withColumn("rowid",row_number().over(Window.partitionBy("id").orderBy(col("updated_date").desc())))

df_unique = df1.filter(df1["row_id"] == 1)

df_baddata = df1.filter(df1["row_id"] > 1)

2. tuple of 2 elements , is this same as a map?

it is not same because

In a map we can only have distinct keys.

but in tuple of 2 like pair rdd keys can be repeated.

3. to save the output in a file we can use

rdd.saveAsTextFile("path where you want the file to be saved")

this is an action just like collect.

because the execution plan is executed when we call saveAsTextFile.

inside jobs you will see actions that you have called

what can count be ? tranformation or an action? count will be single value so we dont need to store it across the cluster so it is an action

whenever we call an action (action 1)....

all the tranformations from the very begining are executed

what happens when you call next action (action 2)


all the tranformations ideally will execute but spark will slightly optimize it by making sure it just executes the last stage because the previous -

stage would have written the o/p to the disk and spark can take it from there and just executes the last stage by skipping all the other stages.

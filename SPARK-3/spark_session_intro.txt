spark session - is a unified entry point of a spark application.

it provides a way to interact with various spark functionality with lesser number of constructs.

instead of having a spark context, hive context, sql context now all of these encapsulated into one.


from pyspark import SparkContext
from pyspark.sql import SparkSession

spark = SparkSession \
        .builder \
        .appName("Hello world") \
        .master("local[2]") \
        .getOrCreate()
        
print(spark.version)

spark.stop()

SparkSession is a singleton - for one application there will be one SparkSession that is why we say getOrCreate()

there cannot be multiple.

Meaning if it is already availabe get it if not create.

.builder() - it returns a builder object

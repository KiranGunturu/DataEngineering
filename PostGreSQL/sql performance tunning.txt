Informatica Performance Tuning
================================

Optimize the target
	Optimizing flat file targets - writing to local target where Integration service is running
	Dropping indexes and key constraints - use pre and post SQL / stored procedures
	Increase database checkpoints
	Using bulk loads - as it bypasses writing database log which speeds performance.
	Using external loads - pipeline with multiple partitions. we can increase performance if we create the oracle target table with same number of
							partitions you use for pipeline
	Increasing database network packet size - allow larger packets of data to cross the network at one time.
											configure in the listener.ora and tnsnames.ora

optimize source
	reduce number of transformations as much as possible
	delete unnecessary links to minimize the data move
	use number columns for group by and order by
	sorted input to agg - decreases the use of agg cahces.
	
transformations
	designate the master source as fewer dup key values / fewer source rows
	perform joins in a database 
	join sorted data
	override the order by in look up transformation
	indexing the look up table

shared cache -
	unnamed cache can be shared between transformations in the same mapping
	named cache can be shared between transformations in same or different mapping
persistant cache -
	when we know our lookup table does not change during session runs - this can improve the performance as integration reads the data cache
	from cache files instead building from database

	WHERE MembershipCode IS NOT NULL;
	
	the index wont work for the below query
	
	SELECT
	*
	FROM Customer
	WHERE MembershipCode = '258410';
	
	To get use of the index, you’ll need to optimize the query in the following way:
	SELECT
	*
	FROM Customer
	WHERE MembershipCode = '258410'
	AND MembershipCode IS NOT NULL;
avoid using multiple OR in the filter predicate
	SELECT
	*
	FROM USER
	WHERE Name = @P
	OR login = @P;
	
	efficient one
	
	SELECT * FROM USER
	WHERE Name = @P
	UNION
	SELECT * FROM USER
	WHERE login = @P;

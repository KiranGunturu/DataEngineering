1. cluster configuration level - resource level Optimization
============================================================

resources - memory (RAM) , CPU cores (Compute)

our intention is to makes sure our job should get right amount of resources.

10 Node cluster (10 worker nodes)

each node has 16 cpu cores and 64 GB ram

Executor (it is like a container of resources)

one node can hold more than one executor

in a single worker node we can have multiple executors (multiple containers)

container - cpu cores + memory (RAM)



16 cores, 64GB RAM

there are 2 strategies when creating containers.

1. Thin executor - intention is to create more executors on one worker node with each executor holding minimum possible resources.

16 executors - each one holding 1 core and 4 gb ram

is this a good way?

drawbacks:

1. the issue is we cannot run multiple tasks inside an executor as it is having only 1 core. loosing the benefit of multithreading
2. A lot of copies of broadcast variable are required as each executor should receive its own copy and that will goto storage memory.

2. Fat executor - intention is to give maximum resources to each executor.

16 cores and 64 gb ram - in this case.

you can create a executor which can hold 16 cpu cores and 64 gb ram

drawbacks:

1.it is observed that if the executor holds more than 5 cpu cores then the hdfs throughput suffers. because lot of i/o due to multiple threads.

2. if executor holds very huge amount of memory then garbage collection takes lot of time.

garbage collection means - removing unused objects from memory.

import random

def randomGenerator:
	return random.randint(1,60)
	
def myFunction(x):
	if(x[0][0:4]=="WARN"):
		return("WARN",x[1])
	else:
		return ("ERROR",x[1])
		
rdd1 = sc.textFile("bigLogNew.txt")

rdd2 = rdd1.map(lambda x:(x.split(":")[0] + str(randomGenerator()),x.split(":")[1]))

rdd3 = rdd2.groupByKey()

rdd4 = rdd3.map(lambda x: (x[0] , len(x[1])))

rdd4.cache()

rdd5 = rdd4.map(lambda x: myFunction(x))

rdd6 = rdd5.reduceByKey(lambda x,y: x+y)

rdd6.collect()

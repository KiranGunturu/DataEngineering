session-7
===========
our problem statement is to find the freqency of each word in the 10 seconds sliding window

reduceByKey - stateless transformation - one rdd
updateStateByKey - stateful transformation, it consider the entire dstream from the beginning to the end. - all rdds

instead of one rdd and all rdds, what if I want to consider certain rdds or moving window?

slicing window: few parameters
1. batch interval - the time in which each rdd is created.
if we have batch interval as 2 seconds that means after every 2 seconds a new rdd will be created.

2. window size - 10 seconds. we are interested in the last 5 rdds only (10/5=2)

3.sliding interval - 2 seconds

after every 2 seconds one oldest rdd will go away and the new rdd will come in

if the sliding interval is 4 seconds

after every 4 seconds 2 oldest rdds will go away and two new rdds will come in


sliding interval has to be integral multiple of batch interval

window size should also be an integral multiple of batch interval

reduceByKeyAndWindow is the transformation can be used

reduceByKeyAndWindow takes 4 parameters

1. summary function (Rdds entered the window) (x,y)=>x+y
2. inverse function (RDDs left the window) (x,y)=>x-y
3. window size - Seconds(10)
4. sliding interval - Seconds(2)


//create spark streaming context

//create spark streaming context
val ssc = new StreamingContext(sc, Seconds(5)) / create RDD for every 5 secs
// lines is a dstream
val lines = ssc.socketTextSteam("localhost",9998)

ssc.checkpoint(".") /creates the checkpoint dir in the current working dir
//transformed DStream

def summaryFuct(x: String, y: String) = {
	(x.toInt + y.toInt).toString()
}

def inverseFuct(x: String, y: String) = {
	(x.toInt - y.toInt).toString()
}

val wordCounts = lines.reduceByKeyAndWindow(summaryFuct,inverseFuct, Seconds(10), Seconds(2))
wordCounts.print()
ssc.start()
ssc.awaitTermination()

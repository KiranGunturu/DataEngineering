session takeaways
===================

1) if we want to add new column to a dataframe then use .withColumn transformation

2) how to convert dataframe to dataset, it is by using case class
	
	lets say we have dataframe called df

	case class Person(name: String, age: Int, city: String)
	
	import spark.implicits._

	val ds = df.as[Person]
	
3) how toconvert dataset to dataframe , using .toDF()

	df = ds.toDF()

4) creating udf in spark.

	1) column object expression - function is not registered in the catalog
	2) SQL expression (easier way)
		
		the function is registered in catalog. so that we will be able to use it with spark sql also
		
	whenever we register a UDF with driver.
	
	driver will serialize it (convert it into bytes) and will send it to each executor

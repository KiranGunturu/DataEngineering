6) what is a pure function?

	1) input solely determines the output
		1a) sqrt(4) - here the inpit is not influences by any other things. //pure function
		1b)
			dollerToRs(40) - 2800 rs in one day
			dollerToRs(40) - 3000 rs in one day // in this function 4o is not the one but there are few other things influences //Not a pure function
	
	2) the function does not change its input value
	3) there are no side effects, this means the function only do whatever it is intended for. its does not do anything extra


	is there any easy way to test if function is pure?
	
		yes, we use referential transparency
		
		A function is referentially transparent if replacing the function with a value do not impact the result.
		
		sqrt(4) //2 so whereever we use sqrt(4) function we can pass a value directly as it will not impact the result.
		
7) First class function: whatever we were able to do with values in traditional programming, same thing we should be able to do with the functions as well.

	by default , In scala all are first class functions

	A function should allow following

	1. we should be able to assign a function to a variable just like we assign value to a variable.

		var a = 5

		def doubler(i: Int): Int = {
		return i*2
		}

		var a = doubler(_)
		a(3) //6

	2. we can pass function as a parameter to another function.

		
		
		def tripler(i: Int): Int = {
		return i * 3
		}
		
		def func(i:Int, f:Int => Int) = {
		f(i)
		}
		
		func(5,tripler)

	3. we should be able to retrun function from a function.

		def func = {
		x:Int = x * x
		}
		
		func(4) //16

def genericSum(x:Int, y:Int, f:Int => Int) = {
f(x)+f(y)
}


genericSum(2,3,x=>x) //5
f(x) 2
f(y) 3


genericSum(2,3,x=>x*x) //13
f(x) = 2*2
f(y) = 3*3

genericSum(2,3,x=>x*x*x) // 35


f(x) = 2*2*2
f(y) = 3*3*3


val sumOfSquares = genericSum(_:Int,_:int,x=>x*x)

sumOfSquares(3,4) //25

sumOfSquares(12,13) //25


val sumOfCubes = genericSum(_:Int,_:int,x=>x*x*x)


sumOfCubes(12,13) //3925

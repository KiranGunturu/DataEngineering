scala supports:

Object oriented style

functional programming style

as a big data side we mainly focus on functional programming style

object learnings2 {

	def squareIt(x: int): Int = {
	x*x
	}
	
	or 
	
	def squareIt(x: Int) = x*x
	println(squareIt(4)) //16
	
	
	def cubeIt(x: Int) = x*x*x
	println(cubeIt(2)) //8
	
	========passing function as a parameter===== beauty of functional programming
	
	
	def transformInt(x: Int, f:Int => Int): Int = {
	f(x)
	}
	
	now we can pass squareIt function as f
	
	transformInt(2, squareIt)
	
	now f(x) will be treated as squareIt(2)
	
	
	transformInt function is called as higher order function
	
	transformInt(2, x=> x*x*x) // a function without a name (Anonymous function)
	
	transformInt(4, x=> x/2) //2
	
	transformInt(2, x => {val y = x * 2; y * y}) //16

========
Array
========

val a = Array(1,2,3,4,5)

println(a.mkString(",")) //1,2,3,4,5

for (i <- a) println(i)

Array is mutable. Index starts with 0.

searchig is very fast.

Adding a new element is tricky and is inefficient operation.

===========
List
===========

val b = List(1,2,3,4,5)

println(b.head) //1
println(b.tail) //List(2,3,4,5)

for (i <- b) println(i)

b.reverse

List - elements of the same datatype

Index starts with 0

Internally holds the elements in a singly linked list.

List is mutable

searchig is not that efficient but adding a new element at the starting is efficient.

========
Tuples

val x = ("Kiran",10000,True)  -- can hold elements of different datatypes

x._1 //Kiran

val y = (107,"Kiran")

if we have a tuple of 2 elements then it is considered as a special case.

it can be treated as key value pairs

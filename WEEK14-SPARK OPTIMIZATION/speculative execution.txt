speculative execution
======================

speculative execution happens when one of the task is taking longer time compared to others.

it will run the same task on the other node only when there is an issue with the worker node like overload, about to crash.


speculative task does not help in following

1. data skew
2. memory crisis.


spark.speculation.interval=100ms

spark check for tasks which can be speculative in 100ms loop

spark.speculation.multiplier=1.5

task is speculative only if it takes more than 1.5 times the median of other tasks execution times.

so if the median value of other tasks is 5 secs then task can be speculative if and only it takes more than 7.5 secs.


spark.speculation.quantile=0.75

if more than 75% of tasks are complete and one task is still struggling then spark will consider that as speculative task.

spark.speculation.minTaskRuntime=100ms

min time that task should run before it is being considered for speculative execution.

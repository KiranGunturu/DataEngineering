s3 standard
	default
	costliest
	data will be automatically repliacted in all the AZ
	used for very freqent data access

S3 standard Infrequent access
	cheaper than standard
	store the data that we dont access very freqently
	
s3 Intelligent tiring
	smart enough to move the data from standard to S3 infreqent access storage depends on the usage and access pattern.
	
	but we have amazon life cycle policy - why do we need intelligent tiring
	life cycle policy is a static - means it will just the move the data when it met the time cycle like 60 days.
	there will be a latency in fetching the data from Infreqent tiring
		hight latency and extra costs when reading from high latency storage places.

s3 one zone IA

s3 glacier

s3 glacier deep archive

S3 Glacier Deep Archive. This storage class is used for long term archiving and the pricing per terabyte of storage in this storage class is only $1.01 USD per month!
 This is incredibly cheap, and very useful for storing data that you very rarely need to access. 
It can take up to 12 hours to have data from this storage class restored to be useable.


block storage
=============
data in a file is broken down into multiple blocks with unique IDs
lowest possible latency
high performing
highly redundant - as data stores in multiple places across the cluster but also helps in fault tolernace
commonly used with SAN
highly scalable
bit expensive


file storage
============

it follows hierarchical strucrure
file organized into folders and sub-folders
files retrived: full path + file name
used in hard drives and NAS (single point of failure)
NAS - multiple hard disks are kept in one box and there will be a n/w switch to give access to other sys who want to access NAS
protocols: NFS, SMB
simple and inexpensive

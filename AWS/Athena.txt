EMR - we create a cluster of machines

for athena we do not have to create a cluster that is why it is called serverless.

No infrastructure is required.

In case of EMR we were paying based on nodes..

for each node we have cost associated per hour.

in athena, we will be charged based on amount of data scanned per query.

In S3 we can store our data in csv, json, parquet, orc etc.

whenever we have infrequent queries.. then we can go for athena.

we can only focus on actual problem statement and we do not have to worry about managing the infrastructure since it is serverless.

$5 per TB scanned.

if we scan 100 MB -

100/1024/1024*5 = $0.00047

5 kb (atleast for 10MB will be charged)

there are no charges for DDL.

if the query fails we are not charged.

what if we cancel the query? then we will be charged for the data which was already scanned.

Is there a automated way to infer the schema?

Glue acts as metastore. (where the metadata is kept (glue catalog)

Glue provides you a crawler as well which can crawl your data and infer the schema out of it.

Glue is an ETL tool too.

Crawler can be on S3, JDBC and dynamoDB.

Crawler can be on demand or on schedule as well - best suited when we think our data/schema might change freqently

Athena's defualt data source is GlueCatalog - we can query the data which is there is Glue catalog tables and databases

Athena stores the query results in the S3. without s3 configured query will not run as athena does not know where to save the results of the query

import boto3
import os
os.environ.setdefault('AWS_DEFAULT_REGION','us-east-1')
athena_client = boto3.client('athena')
athena_client.list_work_groups? - to see the help
athena_client.list_work_groups()
databases=athena_client.list_databases(
			CatalogName='Data source name'
			)
type(databases) //Dict
type(databases['DatabaseList']) //list
databases['DatabaseList']
[database['Name'] for database in databases['DatabaseList']] //get list of database names
tables=athena_client.list_table_metadata(
				CatalogName='data source name',
				DatabaseName='retail_db'
				)

type(tables) //dict
tables['TableMetadataList']

[table['Name'] for table in tables['TableMetadataList']] //get list of tables

table_metadata=athena_client.get_Table_metadata(
				CatalogName='data source name',
				DatabaseName='retail_db',
				TableName='orders'
				)
table_metadata['TableMetadata']['TableType'] //ex: external_Table

table_metadata['TableMetadata']['Columns'] //list of columns with datatypes

table_metadata['TableMetadata']['Parameters']['location'] //table location

[table['Parameters']['location'] for table in tables['TableMetadataList']] //all tables location

run queries
============

athena_client.get_work_group(
			WorkGroup='primary'
			) //to check default query results saving location
			
query_execution=athena_client.start_query_execution(
			QueryString='select count(*) from myretail.orders') //it will give us the query execution id


athena_client.get_query_execution(QueryExecutionId=query_execution[QueryExecutionId])

athena_client.get_Table_metadata(
				CatalogName='data source name',
				DatabaseName='retail_db',
				TableName='orders'
				)

query_str= """
	select order_Status,count(*) as order_count
	from myretail.orders
	group by order_Status
	)
	"""
query_execution = athena_client.start_query_execution(
				QueryString=query_str
				)
				
athena_client.get_query_execution(QueryExecutionId=query_execution[QueryExecutionId]) //to check if succeeded or any errors

query_results=athena_client.get_query_results(QueryExecutionId=query_execution[QueryExecutionId]) //to get query results

query_results['ResultSet']['Rows'] //to see actual data
